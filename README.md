# 🚇 서울 지하철 일별 승하차량 데이터 전처리

## 1단계: `사용일자`를 날짜 기준으로 정리합니다

이 저장소는 상권이동 분석에 사용할 `subway_daily` 데이터셋을 만들기 위한 전처리 과정을 정리합니다.

서울열린데이터광장의 「서울시 지하철 호선별 역별 승하차 인원 정보」 Raw Data에는 `사용일자`가 `20260401`처럼 `YYYYMMDD` 형식으로 들어 있습니다.

이 값을 Python으로 날짜형 데이터로 변환하고, 연도·월·일·평일/주말 구분 컬럼을 생성합니다.

이를 통해 지하철 일별 승하차량 데이터를 연도별·월별·평일/주말별로 분석할 수 있는 `subway_daily` 데이터셋으로 정리합니다.
